# Construction Estimator System

A web-based Construction Estimator System developed using React, TypeScript, and Vite for estimating construction costs, preparing Bills of Quantities (BoQs), and managing construction projects.

## Features

- Dashboard
- Project Management
- Cost Estimation
- Bill of Quantities (BoQ)
- Analytics and Reports

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS

## Installation

```bash
npm install
```

## Run the project

```bash
npm run dev
```

## Build for production

```bash
npm run build
```
